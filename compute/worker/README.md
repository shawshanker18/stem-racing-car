# stem-compute

This repository only runs compute jobs for
[shawshanker18/stem-racing-car](https://github.com/shawshanker18/stem-racing-car).
It holds one workflow, `car.yml`, which checks out that repository at a fixed commit and
runs one case of a batch file per job. Nothing else lives here.

It is created and updated by `compute/setup_compute_repos.py` in the main repository
(bible Part 1). Ask the team lead before deleting it.
